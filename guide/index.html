直流无刷电机编码说明

BL3640-1208
BL = 无刷 36 = 直径(mm) 40 = 长度(mm) 12 = 电压(V) 08 = 版本号
代码段含义示例
前缀（2字母）电机类型BL = Brushless（无刷）
第1组数字（2位）电机外径（mm）36 = 36mm 直径
第2组数字（2位）电机本体长度（mm）40 = 40mm 长度
第3组数字（2位）额定电压（V）12 = 12V
后缀（2位）设计版本/变型08 = 第8个设计变型

直流有刷电机编码说明

RS385-24
RS = 有刷 38 = 直径(mm) 5 = 系列 24 = 电压(V)
代码段含义示例
前缀（2字母）电机类型RS = 有刷直流
第1组数字电机外径（mm）38 = 38mm
第2组数字产品系列5 = 第5系列
后缀数字额定电压（V）24 = 24V

齿轮箱电机编码说明

PG36-BL-100
PG = 行星齿轮 36 = 齿轮箱直径 BL = 搭配无刷电机 100 = 减速比
代码段含义示例
前缀（2字母）齿轮箱类型PG = Planetary Gear（行星式）
第1组数字齿轮箱外径（mm）36 = 36mm
搭配代码配套电机类型BL = 无刷 / RS = 有刷
减速比传动比100 = 100:1
